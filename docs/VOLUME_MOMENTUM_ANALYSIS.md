# 量能分析指标说明

## 📊 概述

量能分析是监控系统中的核心技术指标之一，通过量化价格运动的角度、强度和成交量配合情况，帮助识别趋势的强弱和潜在的反转信号。

本文档详细说明三个核心指标的计算方法、参考价值和实战应用。

---

## 1️⃣ 价格角度 (Price Angle)

### 计算方法

价格角度通过**线性回归**计算最近 N 天（默认5天）价格走势的角度：

```python
# 1. 取最近 period+1 天的收盘价数据
recent_data = df.tail(period + 1)

# 2. 线性回归拟合价格趋势线
x = np.arange(period + 1)  # 时间序列 [0, 1, 2, ..., period]
y = recent_data["close"].values  # 收盘价序列

slope, intercept = np.polyfit(x, y, 1)  # 一元线性回归

# 3. 归一化斜率（消除量纲影响）
price_range = y.max() - y.min()
if price_range > 0:
    normalized_slope = slope / (price_range / period)
    price_angle = np.degrees(np.arctan(normalized_slope))
else:
    price_angle = 0.0
```

### 核心原理

- **线性回归斜率**：反映价格的平均变化速度
- **归一化处理**：将斜率转换为无量纲的相对值，避免高价股和低价股的差异
- **反正切转换**：将斜率转换为角度（-90° ~ +90°），更直观地表示趋势陡峭程度

### 参考价值

| 角度范围 | 含义 | 市场解读 | 操作建议 |
|---------|------|---------|---------|
| **> 30°** | 陡峭上涨 | 上升力量强劲，多头主导 | ✅ 强势买入信号 |
| **15° ~ 30°** | 温和上涨 | 稳步上行，趋势健康 | ✅ 持有或逢低买入 |
| **-15° ~ 15°** | 横盘震荡 | 多空平衡，方向不明 | ⚠️ 观望等待突破 |
| **-30° ~ -15°** | 温和下跌 | 缓慢下行，抛压显现 | ⚠️ 减仓或止损 |
| **< -30°** | 陡峭下跌 | 下降压力巨大，空头主导 | ❌ 强烈卖出信号 |

### 实战案例

**贵州茅台 (600519)** - 2026-04-22
- 价格角度：**-46.1°**
- 解读：陡峭下跌角度，显示强烈的下降压力
- 信号：触发卖出信号，置信度 83%
- AI建议：技术面显示明显下跌压力，建议观望等待企稳信号

### 注意事项

1. **周期选择**：默认使用5天数据，可调整为3天（更敏感）或10天（更稳定）
2. **极端值处理**：当价格波动极小时（price_range=0），角度设为0°
3. **结合其他指标**：单独使用角度可能产生假信号，需配合动量强度和成交量

## 2️⃣ 动量强度 (Momentum Strength)

### 计算方法

动量强度衡量**成交量加权的价格变化方向和强度**：

```python
# 1. 计算每日价格变化
price_changes = recent_data["close"].diff().dropna()

# 2. 获取对应成交量
volumes = recent_data["volume"].iloc[1:].values

# 3. 成交量加权的平均价格变化
weighted_sum = np.sum(price_changes.values * volumes)
volume_sum = np.sum(volumes)

# 4. 归一化到 [-1, 1] 区间
if volume_sum > 0 and avg_volume > 0:
    momentum_strength = weighted_sum / (volume_sum * recent_data["close"].std())
    momentum_strength = max(-1.0, min(1.0, momentum_strength))
else:
    momentum_strength = 0.0
```

### 核心原理

- **成交量加权**：放量上涨/下跌比缩量更有意义
- **标准化处理**：除以价格标准差，消除不同股票波动率的差异
- **取值范围**：-1（极强下跌）~ +1（极强上涨），0为中性

### 参考价值

| 强度范围 | 含义 | 市场解读 | 操作建议 |
|---------|------|---------|---------|
| **> 0.5** | 强上涨力量 | 买方主导，资金流入明显 | ✅ 买入或加仓 |
| **0.2 ~ 0.5** | 温和上涨 | 买盘略占优 | ✅ 持有观察 |
| **-0.2 ~ 0.2** | 力量均衡 | 多空博弈激烈 | ⚠️ 观望 |
| **-0.5 ~ -0.2** | 温和下跌 | 卖盘略占优 | ⚠️ 减仓 |
| **< -0.5** | 强下跌力量 | 卖方主导，资金流出 | ❌ 卖出或止损 |

### 实战案例

**贵州茅台 (600519)** - 2026-04-22
- 动量强度：**-0.92**
- 解读：极强的下跌力量，卖方完全主导市场
- 信号：触发卖出信号，置信度 83%
- 配合：价格角度-46.1°，双重确认下跌趋势

### 注意事项

1. **异常值保护**：限制在[-1, 1]范围内，避免极端行情导致失真
2. **成交量质量**：需确保成交量数据真实可靠（排除对倒等操纵行为）
3. **与价格角度配合**：两者同向时信号更可靠，背离时需警惕

## 3️⃣ 量能力量 (Volume Power)

### 计算方法

量能力量综合反映**成交量放大倍数与价格变化率的乘积**：

```python
# 1. 计算当前成交量相对于均量的倍数
current_volume = recent_data["volume"].iloc[-1]
avg_vol = recent_data["volume"].iloc[:-1].mean()
volume_ratio = current_volume / avg_vol if avg_vol > 0 else 1.0

# 2. 计算期间价格变化率
price_change_rate = (recent_data["close"].iloc[-1] - recent_data["close"].iloc[0]) / recent_data["close"].iloc[0]

# 3. 量能力量 = 成交量倍数 × 价格变化率 × 100
volume_power = volume_ratio * price_change_rate * 100
```

### 核心原理

- **量价配合**：同时考虑成交量变化和价格变化
- **正向放大**：放量上涨时值为正且较大，放量下跌时值为负且较小
- **背离识别**：缩量上涨或放量滞涨时值会显著降低

### 参考价值

| 力量范围 | 含义 | 市场解读 | 操作建议 |
|---------|------|---------|---------|
| **> 5** | 强势放量上涨 | 量价齐升，资金积极介入 | ✅ 强烈买入 |
| **2 ~ 5** | 温和放量上涨 | 买盘持续，趋势健康 | ✅ 持有或加仓 |
| **-2 ~ 2** | 量价平稳 | 正常波动，无明显方向 | ⚠️ 观望 |
| **-5 ~ -2** | 温和放量下跌 | 卖压增加，需谨慎 | ⚠️ 减仓 |
| **< -5** | 强势放量下跌 | 恐慌性抛售，风险极大 | ❌ 立即止损 |

### 典型场景

#### 场景1：量价齐升（理想状态）
- 成交量放大2倍，价格上涨3%
- volume_power = 2 × 3 × 100 = **600**（极强买入信号）

#### 场景2：缩量上涨（背离警示）
- 成交量缩小到0.5倍，价格上涨2%
- volume_power = 0.5 × 2 × 100 = **100**（动能不足，警惕回调）

#### 场景3：放量下跌（危险信号）
- 成交量放大3倍，价格下跌4%
- volume_power = 3 × (-4) × 100 = **-1200**（强烈卖出信号）

### 实战案例

**贵州茅台 (600519)** - 2026-04-22
- 量能力量：**-2.48**
- 解读：温和放量下跌，卖压正在增加
- 配合：价格角度-46.1°，动量强度-0.92，三重确认弱势

## 🎯 综合应用策略

### 1. 三指标共振系统

当三个指标**同向共振**时，信号可靠性最高：

#### 强烈买入信号
- ✅ 价格角度 > 30°
- ✅ 动量强度 > 0.5
- ✅ 量能力量 > 5
- **示例**：角度45° + 强度0.7 + 力量8 = 高置信度买入

#### 强烈卖出信号
- ❌ 价格角度 < -30°
- ❌ 动量强度 < -0.5
- ❌ 量能力量 < -5
- **示例**：角度-46° + 强度-0.92 + 力量-2.48 = 高置信度卖出

### 2. 背离预警系统

当指标出现**背离**时，预示趋势可能反转：

#### 顶背离（看跌）
- 价格创新高，但角度减小、强度减弱
- **操作**：逐步减仓，准备止盈

#### 底背离（看涨）
- 价格创新低，但角度趋缓、强度改善
- **操作**：分批建仓，等待确认

### 3. 置信度计算

系统根据指标强度自动计算信号置信度：

```python
# 基于价格角度的置信度
if price_angle > 30:
    confidence = min(0.85, 0.6 + price_angle / 200)
elif price_angle < -30:
    confidence = min(0.85, 0.6 + abs(price_angle) / 200)

# 基于动量强度的置信度
if momentum_strength > 0.5:
    confidence = min(0.85, 0.6 + momentum_strength / 4)
elif momentum_strength < -0.5:
    confidence = min(0.85, 0.6 + abs(momentum_strength) / 4)
```

## 📈 实战技巧

### 1. 周期选择建议

| 交易风格 | 推荐周期 | 特点 |
|---------|---------|------|
| **超短线** | 3天 | 灵敏度高，噪音多 |
| **短线** | 5天（默认） | 平衡灵敏度和稳定性 |
| **中线** | 10天 | 过滤短期波动，趋势明确 |

### 2. 与其他指标配合

- **均线系统**：角度向上 + 多头排列 = 强势上涨
- **RSI指标**：角度向上 + RSI<70 = 健康上涨；角度向上 + RSI>80 = 超买风险
- **MACD指标**：角度向上 + MACD金叉 = 双重买入确认

### 3. 风险控制

1. **单一指标不可靠**：必须至少两个指标同向才采取行动
2. **设置止损位**：即使信号强烈，也要设置合理的止损点
3. **关注市场环境**：大盘弱势时，个股信号成功率会降低
4. **避免追高杀跌**：角度极端时（>60°或<-60°）反而要警惕反转

## ❓ 常见问题

### Q1: 为什么价格角度会出现负值？
**A**: 负角度表示价格下跌趋势，角度越负表示下跌越陡峭。这是正常的数学结果，arctan函数的值域是(-90°, 90°)。

### Q2: 三个指标哪个最重要？
**A**: 没有绝对的优先级，三者各有侧重：
- 价格角度：反映趋势方向和陡峭程度
- 动量强度：反映买卖力量的对比
- 量能力量：反映量价配合的质量
**最佳实践是三者结合使用**。

### Q3: 如何调整指标的灵敏度？
**A**: 可以修改以下参数：
- `period`：减小周期提高灵敏度，增大周期提高稳定性
- 阈值参数：降低阈值会增加信号数量但可能增加误报

### Q4: 量能分析适合哪些股票？
**A**: 
- ✅ 适合：流动性好、成交量稳定的股票
- ⚠️ 谨慎：新股、停牌复牌股、成交量极小的股票
- ❌ 不适合：无成交量的股票
